# Réseau de collaborations – Raphaël Richert

Page web interactive (inspirée de VOSviewer) montrant les co-auteurs, établissements, pays (carte du monde ou réseau), thématiques et mots-clés à partir des publications.

- `index.html` : la page (D3.js, aucune compilation nécessaire)
- `data.js` : les publications, établissements et thématiques — **c'est le seul fichier à modifier pour ajouter un article**
- `world.js` : fond de carte Natural Earth 1:110m (domaine public)

Ouvrir `index.html` dans un navigateur suffit pour la tester en local.
